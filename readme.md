# Features

- Random activity selection
- Multiple activity types
- Custom game names
- Random status selection
- Multi-threaded execution
- WebSocket heartbeat handling

# Activity Types

- Playing
- Streaming
- Watching
- Listening to

# Installation

**1. Clone the repository**

```bash
git clone https://github.com/NotShadow1337/Discord-Presence.git
cd Discord-Presence
```

**2. Install requirements**

```bash
pip install -r requirements.txt
```

**3. Configuration**

Create a local `tokens.txt` file containing your credentials, one entry per line.

**4. Run**

```bash
python main.py
```

# Configuration

You can customize the following settings inside `main.py`:

- Activity types
- Game names
- Status options
- Streaming URL
